# Task Automation

A robust and efficient Python-based automation project designed to simplify repetitive tasks, streamline workflows, and improve daily productivity.

## Features

- **Task Automation:** Automates repetitive tasks and processes.
- **Python Integration:** Developed using Python.
- **Image Management:** Includes a destination images folder.
- **Easy to Use:** Simple project structure and configuration.
- **Extensible:** Can be enhanced with additional automation features.

## Project Structure

```text
Task_Automation/

├── destination_images/
│   ├── photo1.png
│   ├── photo2.png
│   └── photo3.png
│
├── main.py
└── README.md
```

## Requirements

- Python 3.x

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/adarshguptas/Task_Automation.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Task_Automation
   ```

3. Run the Python script:

   ```bash
   python main.py
   ```
